# Onboarding Animated Soundtrack

## External Animated Soundtrack from Web

The onboarding now features an animated soundtrack sourced from the web instead of generated audio.

### External Animated Soundtrack

The system uses an external animated soundtrack from reliable web sources:

#### Current Implementation:
- **Source**: External web audio files
- **Format**: WAV, MP3, OGG
- **Auto-play**: Starts when page loads
- **Loop**: Automatic looping
- **Volume**: 30% by default
- **User Control**: Can pause/resume

#### Audio Sources:
- **Primary**: SoundJay animated sound effects
- **Fallback**: Multiple source URLs for reliability
- **Format Support**: WAV, MP3, OGG formats
- **No Copyright**: Free, no-copyright sources

### Implementation Details:
- Audio loops automatically
- Volume set to 30% for optimal experience
- User can toggle play/pause
- Audio starts automatically when page loads
- Graceful fallback if external files fail
